## 三分钟上手

### 第1 步：打开文件

双击 `workbench.html`，浏览器会打开。

> **推荐Chrome 或 Edge。** 后续版本的「自动写回本地文件」功能依赖
> File System Access API，仅 Chromium 系内核支持。

### 第 2 步：分配策划案编号

进入 **§0 基本信息** → **0.1 立项标识** → 点「**分配编号**」。

工具会生成形如 `CX-20261004-01` 的编号，规则是 `CX-年月日-当日序号`。
这个编号是**只读**的，且是本策划案在目录、台账、成片侧的**唯一主键**。

- 同一天多次建案：序号自动递增（`-01` → `-02`）
- 换一天：序号重置
- 编号填错了：再点一次会**释放**旧编号再分配，不会占用

### 第 3 步：填核心信息

按顶栏「**强制项完成度**」的提示逐项补齐。分母是所有必填项的总数，
分子是已完成的。**全部填完才能导出。**

### 第 4 步：导出

见 [导出](#导出) 一节。

## 界面总览

```
┌──────────────────────────────────────────────────────┐
│ 顶栏：进度条 + 强制项完成度 + 模式切换 + 主题切换 + 导出 │
├──────────┬───────────────────────────────────────────┤
│          │                                           │
│ 侧边栏    │  主内容区（12 个章节，纵向滚动）              │
│ · 章节导航 │                                           │
│ · 每节的   │                                           │
│   完成度   │                                           │
│          │                                           │
└──────────┴───────────────────────────────────────────┘
```

### 三种模式

顶栏可切换：

| 模式 | 用途 |
|---|---|
| **编辑** | 日常填写。控件齐全 |
| **预览** | 只看内容，隐藏交互控件——用来检查成稿效果 |
| **核对** | 高亮所有未填项——导出前自检用 |

### 深浅主题

顶栏右侧切换。默认浅色（打印所见即所得），暗色适合夜间填表。

## 逐章节操作

### §0 基本信息

| 小节 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 0.1 | 策划案编号 | 🟥 | 点按钮自动分配，只读 |
| 0.1 | 策划方案版本号 | 🟥 | 默认 `v1.0`，实质变更时自己递增 |
| 0.1 | 撰写日期 | 🟥 | 默认今天，**也是编号的日期来源** |
| 0.2 | 拍摄日期 | 🟥 |填了会显示星期 |
| 0.2 | 拍摄时段 | 🟥 | 上午 / 下午 / 晚上 |
| 0.2 | 预计时长 | — | 小时数，用于与 §7 行程表比对 |
| 0.3 | 地点名称 / 详细地址 | 🟥 | 精确到可导航；室内写楼层与厅 |
| 0.3 | 场地所在区 | — | 选填 |
| 0.4 | 拍摄主题 | 🟥 | 全案锚点，一句话概括创作意图 |
| 0.5 | 题材分类 | 🟥 | 沿用 T1-1 模板枚举 |
| 0.5 | 成片类型 | 🟥 | 含「视频」时联动分镜脚本 |
| 0.6 | 拍摄性质 | 🟥 | 客片/ 互勉 / 创作 / 商业合作 / 其他 |
| 0.6 | 收入金额 | 条件🟥 | 选「商业合作」或「其他」时必填 |
| 0.6 | 负责摄影师 | 🟥 | — |
| 0.7 | 本场模特姓名 | 🟥 | 完整档案在 §1 填 |

> **v1.0.0 变更**：0.3与 0.7 原先有「从场地库/模特库选择」下拉，
> 因与§4 / §1 主数据源重复已下线。现在 §0 只填当次的文字信息。

### §1 模特

姓名/ 身高 / 体重 + **样图 1-2 张**（推荐正脸 + 全身各1 张）。

- 样图**至少 1 张**才计入必填
- 点图片放大查看，点右上角 **✕** 删除
- 填完点「**存入模特库**」→ 下次该模特直接「调入」，不用重填

### §2 服装

**上下身、鞋袜已融合为一行**——旗袍、连衣裙等连体服饰无法拆分。

| 列 | 说明 |
|---|---|
| 类别 | 上装 / 下装 / 连体 / 鞋 / 袜/ 配饰 |
| 品类 / 款式 / 质料 / 颜色 | 自由填写 |

**配饰**默认显示一行，点「＋ 添加行」继续加。

### §3 妆造

必填恰好 4 项：

- 妆面**整体风格** + **妆面参考图**（1 张）
- 发型**风格** + **发型参考图**（1 张）

腮红、口红、眼影等**都是选填**。

### §4 场地

档案 7 要素：名称 / 所在区 / 适配风格 / 是否时效性 / 门票 / 简述 / 参考图。

- 「是否时效性」只有**是 / 否**两个选项
- 选「是」时 §10 应急会提示需提前确认档期
- **参考图建议 5-10 张**（上限 10），一次可多选
- 点「存入场地库」后可复用

### §5 道具

- **5.1 清单表**：名称 / 类别（拍摄·互动·氛围·实用）/ 数量 / 备注采购情况，可增删行
- **5.2 参考图**：建议 1-8 张

> 只有「名称」非空的行才计入必填。

### §6 摄影器材

| 小节 | 内容 |
|---|---|
| 6.1 | 器材清单（机身 / 镜头） |
| 6.2 | 滤镜 |
| 6.3 | 灯光器材——**只登记「带了什么灯」** |
| 6.4 | 附件（���脚架 / 柔光罩 / 蜂巢…） |
| 6.6 | 器材总清单 + 存储卡换算 |

> **6.3 与 §6.5 的区别**：§6.3 是器材**资产登记**（带了什么），
> §6.5 是**布光方案**（灯怎么摆、功率多少、控光怎么加）。两处不重复。

**存储卡换算**：填容量（GB）后自动估算可拍张数，按 0.8 安全系数折算。
勾选「在导出文档中展开完整算式」则把推导过程一并写进文档。

### §6.5 布光方案

**先选方案类型**：

| 方案 | 适用 | 6.5.3 3D 渲染图 |
|---|---|---|
| **严谨** | 需要精确控光的商业拍摄、夜拍、大型灯具 | **显示**（必填） |
| **快捷** | 外景随手拍、记录性拍摄 | **整节不显示**，可正常导出 |

- **光位规划**默认只显示「主光」一行，点「＋ 添加灯位」继续加
- 光位9 项 / 光线方向 11 项，都是单选
- 切换方案时**已填数据保留**，切回严谨可恢复

### §7 行程安排

三个子节：

**7.1 拍摄日时段轴**（甘特式）
点任一关键节点（妆造/ 布光 / 拍摄 / 黄金时刻 / 日落 / 收工）
→ 自动设为行程起点时间。

> ★ **黄金时刻**与**日落**是拍摄日最不可错过的两段，
> 逆光、剪影、氛围片都靠这两段。
> 具体日落时刻随纬度与日期变化（冬季日落早约 1 小时），**以拍摄地当日实测为准**。

**7.2 Timetable**
时间 / 事项 / 地点 / 耗时 / 备注，可增删行。

**7.3 耗时汇总**
自动累加各行耗时，与 §0.2「预计时长」比对：
差 ≤10 分钟显示吻合；超出/ 缺口会给出调整建议。

> **人员分工不在本节范围内**（v1.0.0 口径确认）。

### §9 注意事项

5 条活动须知，**纯文本、无勾选、不阻塞导出**：

1. 拍摄活动**安全第一**，严禁做出危险动作，违者后果自负
2. 拍摄活动欢迎各位男、女摄影师，**非擦边拍摄活动**，有非分之想之人请自觉离开
3. 拍摄活动**全程无接触**，禁止摄影师与模特产生任何形式的肢体接触
4. 参加本活动所产生的照片**默认摄影师与模特双方皆同意发布至社交媒体平台**，若涉及商业用途，需经过双方授权
5. 拍摄活动请妥善保管、保护好自己的随身物品、拍摄设备、道具等，**产生丢失及损坏后果自负**

下方**签署确认表**含模特、摄影师两行。打印或「另存为 PDF」即带走完整须知与签字栏。

> 需要独立可发版本见 [`pre-shoot-checklist.md`](../pre-shoot-checklist.md)。

### §10 应急预案

8 类风险 × 触发条件 × 应对措施：下雨、大风、场地人流过大、模特迟到/缺席、
设备故障、内存不足、妆造失败、天气突变。

| 字段 | 必填 | 说明 |
|---|---|---|
| 当天唯一决策人 | 🟥 | 所有顺延/改场地/收工的决定都由此一人拍板 |
| 决策时点 | — | 选填。多数情况当场决策即可；有明确提前量时才填 |

### §11 参考样片

**5-25 张**。建议覆盖：色调 / 构图 / 光位 / 妆造 / 服装 / 氛围。

- 不足 5 张会显示醒目提示，且**拦住导出**
- 达 25 张后隐藏添加槽
- 点图片放大，点右上角 **✕** 删错图

## 数据管理

### 数据存在哪

浏览器 **localStorage**，键名：

| 键 | 内容 |
|---|---|
| 策划案 | 全部章节内容 |
| `sw_models` | 模特库 |
| `sw_venues` | 场地库 |
| `sw_usedno` | 已占用的编号 |

**不上传任何服务器**，图片以 base64 存在本地。

### 容量上限

实测 **4.94 MB**。参考：

| 内容 | 体积 |
|---|---|
| 单张压缩后图片 | 约 59 KB |
| 单个满配场地（10 图） | 约 593 KB |

→ 约 **6 个满配场地**后触顶。触顶时数据写入会静默失败。

> **建议**：场地库控制在 6 处以内，或用 CSV 导出后清理（见 v2.0 计划）。

### 换设备 / 备份

当前版本**没有**导出整份策划案的按钮，数据迁移靠浏览器本身：

- 同设备：数据在，随便刷新
- 换设备：**需手动重建**（v1.1 计划加「导出整案 JSON」）
- 备份：把 localStorage 截图/导出，或用CSV 导出模特库与场地库

## 常见问题

**Q：导出时提示「还有必填项未填」，但我看不到缺哪个**
切到「**核对**」模式，会高亮所有未填项。

**Q：编号能不能自己改**
不能，这是设计。编号是主键，手改会导致台账与成片对不上。
填错就再点一次「重新分配」，会释放旧号。

**Q：图片传上去会被裁掉吗**
不会。图片槽用 `object-fit: contain` 完整显示，宽高比与格子不符时留白而非裁切。

**Q：为什么样图只能传 2 张、参考样片能传 25 张**
样图是「选角参考」，2 张够判断尺码与气质；
参考样片是「风格对齐」，需要覆盖多个维度故给到 25 张。

**Q：§6.3 和 §6.5 都要填灯，重复吗**
不重复。§6.3 登记「带了什么灯」（资产），§6.5 规划「灯怎么摆」（布光）。
两处信息量不同。

**Q：数据会丢吗**
清浏览器数据、换浏览器、换设备都会丢。
localStorage 在同一浏览器同一路径下是持久的。

**Q：能多人协作吗**
不能。这是单机工具。多人在同一策划案上协作需等飞书同步（v3.0，优先级最低）。

**Q：为什么没有 §8 和 §12**
开发过程中裁掉的。§8「后期需求」的内容曾并入 §11，
后随 §11.2 一并删除；§12「交付与确认」属导出后的人工动作，原型不做。
详见 [CHANGELOG](../CHANGELOG.md)。
