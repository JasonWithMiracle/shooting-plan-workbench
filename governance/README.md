## 工作流约定

1. **先本地**：任何产出先写入本地目录，不直接往云盘丢。
2. **再确认**：上传云端前必须把本地版本给Jason 过目，明确确认后才执行上传（严禁本地改完直接覆盖云端）。
3. **后同步**：确认后上传至云端同名文件；云端保持扁平单层，文件名与本地一致。

## 文件命名规范

`项目名_内容类型_版本_YYYYMMDD.ext`

- 项目名：拍摄项目/客户简称，不含空格与特殊符号
- 内容类型：`策划案` / `脚本` / `分镜` / `拍摄清单` / `预算` / `素材` / `交付` / `沟通记录`
- 版本：`v01` 起递增，`vFINAL` 为定稿版
- 示例：`某品牌秋季发布_策划案_v02_20261004.docx`
